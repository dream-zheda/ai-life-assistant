# AI 个人生活助手 · 用户使用说明书

**适用版本：当前本地部署版（含 QQ AI 对话与手机访问）**  
**文档版本：1.0 · 更新日期：2026 年 11 月 5 日**

你提供自己的情况、目标和不能挪动的时间，助手生成具体的日常安排。确认计划后，可以通过网页查看进度，在 QQ 接收提醒、反馈完成情况，也可以直接和 AI 聊天。

---

## 1. 先认识这个助手

它适合希望兼顾学习、工作、运动、休息和娱乐，又经常忘记行动或难以开始的人。它不会要求你先手工排好整张时间表；你主要需要说明自己的实际生活，让 AI 帮你安排。

| 你想做什么 | 使用位置 | 当前能做到什么 |
| --- | --- | --- |
| 让 AI 了解你 | 我的情况 | 保存个人背景、作息、偏好和固定安排 |
| 明确想达成的事情 | 我的目标 | 添加、编辑目标，设置优先级与期望日期 |
| 规划今天 | 今日概览 | 生成计划草稿，确认采纳，查看安排与完成进度 |
| 换一家模型服务商 | 模型配置 | 配置 DeepSeek、OpenAI 或 OpenAI 兼容接口 |
| 收到提醒并反馈 | 提醒通道 → QQ | 验证绑定自己的 QQ，接收提醒，回复进度指令 |
| 和 AI 讨论日常问题 | QQ 好友私聊 | 根据个人情况、当天生效计划及最近对话生成回复 |
| 减少打扰 | 偏好设置 | 设置早报时间、提前提醒、免打扰和提醒上限 |
| 邀请别人使用 | 邀请管理，仅管理员可见 | 生成、复制完整注册链接，查看邀请状态或撤销 |

**当前范围：**普通 QQ 聊天提供建议，实际修改计划仍需在网页操作。系统不会监控你正在玩什么游戏，不会自动判断你是否完成任务，也不能强制关闭游戏。当前日计划需要你主动生成并采纳，不要把每天自动生成新计划视为已提供的功能。

## 2. 打开网站与注册登录

### 手机访问

当前入口：[打开生活助手](https://你的公网地址/sign-in)。可以在手机浏览器中打开，用原网站账号登录，无需安装 App。

此地址使用 cpolar 国内节点，但仍需以你的实际手机网络访问结果为准。免费隧道的地址会变化；打不开旧地址时，请向管理员索取最新入口。可以使用浏览器的“添加书签”或“添加到主屏幕”，但这不代表网站支持离线运行。

### 新用户注册

1. 向管理员领取**完整邀请链接**，不要只复制邀请码或 `/sign-up` 开头的路径。
2. 打开链接，确认注册页显示已带上邀请码。
3. 填写称呼、邮箱和密码，密码至少 8 位。
4. 点击“创建账号”，成功后进入模型配置。

邀请码一次有效，并受有效期限制。已使用、已撤销或过期时，需要管理员重新邀请。已有账号直接登录，不用再次注册。

本产品采用多用户账号：每位用户分别维护自己的情况、目标、模型配置、计划和 QQ 绑定。成为机器人好友不会自动获得别人的计划或账号权限。

## 3. 第一次使用：按这个顺序完成

1. **登录网站。**新用户从完整邀请链接注册。
2. **连接模型。**填写模型服务商信息，测试连接，再保存配置。
3. **介绍自己。**在“我的情况”保存背景，并添加不能挪动的固定安排。
4. **设置目标。**在“我的目标”写明想达成的事情和优先级。
5. **绑定 QQ。**添加机器人好友，并完成一次性绑定码验证。
6. **生成并采纳计划。**到“今日概览”生成草稿，检查后点击采纳。
7. **开始执行。**到点接收提醒，在网页或 QQ 反馈进度。

**建议的首次验证：**选择一项尚未开始的安排，确认计划已生效、QQ 已绑定且提醒没有暂停，等待提醒并回复进度。不要用已经结束的任务验证定时提醒。

## 4. 配置 AI 模型

进入“模型配置”，填写以下四项：

| 项目 | 填写方法 |
| --- | --- |
| 模型服务商 | 选择 DeepSeek、OpenAI，或“自定义（OpenAI 兼容）” |
| 接口地址 | 使用服务商提供的 API 基础地址，不是普通聊天网页地址 |
| 模型名称 | 填服务商给出的模型 ID；名称以服务商当前文档为准 |
| API Key | 在对应服务商后台创建并复制的密钥，不是网站登录密码 |

操作顺序是：**填写 → 测试连接 → 保存模型配置**。测试成功不等于已经保存。测试连接、生成计划和 QQ 对话都可能产生模型 API 费用，具体以服务商计费规则为准。

DeepSeek 页面预设接口为 `https://api.deepseek.com/v1`，模型预设为 `deepseek-chat`。如果你的账号使用其他模型，按实际可用的模型 ID 修改。

更换服务商或接口地址时，需要填写对应的新 Key。服务商和地址未改变时，页面允许留空保留已保存的 Key。切换模型不会删除原来的个人情况、目标和计划。

当前网页和 QQ 聊天主要使用 **OpenAI 兼容协议**。选择“自定义”不表示任意厂商的任意原生 API 都能直接接入。QQ AI 对话需要该用户保存可用的个人模型配置。

## 5. 告诉 AI 你的生活是什么样的

### 个人情况怎么写

进入“我的情况”，用自然语言说明：平时身份或工作、作息、精力特点、容易遇到的困难、娱乐需求，以及希望怎样被安排。

可以参考这个例子，再改成自己的真实情况：

> 我是大学生，白天有课，晚上容易打游戏忘记学习。想每天练英语，也想每周运动几次。我不希望一天安排太满，晚上要保留娱乐时间。学习刚开始时容易拖延，希望先安排短一点的任务，再逐渐增加。

写具体情况比只写“我要自律”更有帮助。生活变化后记得更新；保存在这里的信息不会自动改写已经生效的计划，需要再重新规划。

### 固定安排怎么填

睡觉、上课、上班、通勤等不能随意挪动的时间，应填入“固定安排”，不要只埋在长段描述里。

例如：名称“睡觉”，重复方式“每天”，开始 23:00，结束 07:00。支持跨夜安排，也可选择工作日、周末或指定某一天。填好后点击“保存我的情况”。已有固定安排可在页面中编辑或删除。

### 目标怎么填

在“我的目标”填写目标名称、“当前情况与期待”、优先级，以及可选的期望日期。**1 为最高优先级，5 为最低。**

例如：“提高英语听力”；当前情况：“能看懂简单句子，但听力容易跟不上，希望每天先练 15 分钟”；优先级设为 1。建议起初只放少量重要目标，避免有限空闲时间被分得太碎。

## 6. 生成、采纳与调整今天的计划

1. 打开“今日概览”，点击“生成今天的计划”。
2. 等待生成，检查草稿里的任务、时间、时长及规划依据。
3. 确认与实际生活一致后，点击页面上的采纳按钮。
4. 看到计划生效提示后，再按安排执行。

**生成草稿 ≠ 计划生效。只有已采纳的生效计划才进入提醒流程。**生成计划后没有立刻收到 QQ 消息，不一定是故障：开始提醒需要等到对应提醒时间，早报也受设置时间限制。

采纳时，已经结束的条目可能被跳过。重新生成会产生新草稿，仍需确认；新版本采纳后替代原生效版本。

安排不合理时，先修正“我的情况”、固定安排或目标优先级，再点击“重新规划今天”，检查并采纳新的版本。当前不是在 QQ 随便说一句“全部推迟半小时”，系统就会自动执行。

完成任务后，可以在今日安排中使用进度按钮反馈。未反馈的任务不会因为时间已过就自动算作完成。页面中的“今日提醒”可用于查看提醒内容和处理状态。

## 7. 连接 QQ 机器人

当前机器人账号：**3463802115**。以网站“提醒通道 → QQ”页面显示的账号为准。

1. 用你准备接收提醒的 QQ 添加机器人好友。
2. 等待好友申请通过。当前已开启自动通过，通常需要几秒至一分钟；实际取决于机器人和后台是否在线。
3. 回到 QQ 连接页面领取绑定码。
4. 将页面给出的**整条绑定消息**私聊发给机器人，格式为 `绑定 16位绑定码`。
5. 等待页面显示“已验证绑定”，并核对接收提醒的 QQ 号。

绑定码有效期为 10 分钟，只能使用一次。过期后重新领取。**加好友不等于绑定成功。**普通用户不需要安装 NapCat，也不需要把 QQ 密码交给管理员。

每个网页账号绑定自己的 QQ；一个 QQ 不能同时绑定两个网页账号。更换接收账号时，先在网页解除旧绑定，再使用新 QQ 完成验证。

## 8. QQ 聊天与进度指令

### 自然语言聊天

绑定成功、机器人在线并保存可用模型配置后，直接发送文字即可，无需另外开启聊天开关。

例如：

> 我今天不想学英语，能不能给我一个五分钟能开始的方法？

> 结合今天的安排，我应该先做哪件事？

> 我最近总是玩游戏过头，怎么给娱乐时间设一个容易执行的边界？

助手会参考个人情况、当天已生效计划和最近一段对话。成功对话会保存；当前上下文会取最近 12 条消息，并不是无限记住所有历史。单条文字建议控制在 1000 字以内，过长内容会截断。密集发送时可能提示稍后再试。

当前只支持好友私聊文字，不支持群聊、语音或图片理解。普通对话给出建议，不能据此认为计划或提醒设置已经被修改。

### 完成情况怎么回复

| 发送内容 | 含义 |
| --- | --- |
| `1` | 完成刚刚提醒的那一项 |
| `2` | 刚刚提醒的那一项做了一半 |
| `3` | 跳过刚刚提醒的那一项 |
| `完成 2` | 将当天第 2 项记录为完成 |
| `一半 2` | 将当天第 2 项记录为做了一半 |
| `跳过 3` | 将当天第 3 项记录为跳过 |
| `帮助` | 查看指令提示 |

**数字 `2` 不是“完成第 2 项”。**裸数字用于最近的单项提醒，系统会查找最近两小时内相关提醒；找不到时不会猜测任务。看完包含多个任务的早报后，优先使用带序号的明确指令，并核对机器人回执中的任务名称。

如果帮助文案出现“今天累了会把安排往后挪”等仍在开发的描述，请以本说明书为准：当前聊天不会自动移动日程。

## 9. 提醒与免打扰

进入“偏好设置”，调整后点击“保存设置”。时间按账号显示的本地时区执行。

| 设置 | 作用 |
| --- | --- |
| 每天几点发早报 | 设置日计划早报的时间；需要当天已有生效计划及服务在线 |
| 提前多少分钟提醒 | 可设 1–120 分钟，控制开始提醒的提前量 |
| 免打扰开始／结束 | 两项一起填写，支持跨夜；都留空表示不设置 |
| 每天最多几条主动提醒 | 可设 0–50 条；设为 0 会阻止主动提醒 |
| 暂停所有提醒 | 暂停主动提醒，保留已有计划 |

免打扰、提醒上限及暂停主要约束主动提醒，不应理解为一定会禁止你主动发起的 AI 对话。被抑制的提醒不会保证稍后补发；关闭电脑或机器人离线期间错过的提醒也不要依赖自动补齐。

网站记录通道接受了消息，并不等于已经确认你的手机收到。收信异常时，可以先到“今日概览 → 今日提醒”查看站内记录。

## 10. 管理员：邀请别人使用

进入“邀请管理”，填写可选的邮箱备注和有效期，点击“生成邀请码”。有效期可选 1–720 小时，默认 72 小时。

生成后，使用“**复制邀请链接**”把完整 HTTPS 链接发给受邀者。也可以点“打开注册页面”检查入口。不要分享管理员页面地址。

完整链接的结构是：网站域名 + `/sign-up?invite=` + 邀请码。不要只发送最后一段码，或只发送以 `/sign-up` 开头的路径。

当前邮箱字段仅是备注，不限制必须由该邮箱注册；获得链接的人可能使用这条邀请，因此应只分享给预期使用者。待使用邀请可在列表撤销。

出于凭据保存方式的限制，邀请码明文只在生成结果中出现，列表不能恢复旧码。若生成结果页已经关闭且没有复制原链接，可以生成新邀请，按需撤销旧邀请。

网站域名变化后，管理员需要同步更新分享地址配置。请避免继续发送包含旧域名的邀请链接。

## 11. 数据、费用与账号操作

- **模型费用：**使用你配置的服务商 API，费用由对应服务商规则决定。网站账号与模型服务商账号是两回事。
- **数据使用：**生成计划或 QQ 回复时，必要的个人情况、目标、计划或最近对话会传给所选模型服务商。QQ 消息经过 QQ 通道，公网网页流量经过隧道服务。
- **数据访问：**普通用户在产品内查看自己的数据。部署方的服务器与数据库管理员具备维护数据的能力，不能把本产品理解为端到端加密的私人保险箱。
- **下载数据：**“偏好设置 → 下载我的数据（JSON）”，导出个人情况、目标、计划、进度、对话及提醒等记录，不包含密码、会话令牌或模型 Key。
- **删除账号：**“偏好设置 → 账号删除”，按页面要求输入确认文字后提交。此操作无法在产品内恢复，建议先导出数据。

页面中关于每日备份及保留天数的文字，不代表当前这台电脑已经完成自动备份配置。实际备份是否启用、删除后的备份何时过期，由管理员核实维护。

当前没有在登录界面提供自助找回密码入口。忘记密码请联系管理员，不要反复注册或向他人发送原密码。

## 12. 常见问题

| 遇到的问题 | 按顺序检查 |
| --- | --- |
| 手机打不开网站 | 是否使用最新地址；电脑是否联网且未休眠；网站和 cpolar 是否运行；换手机浏览器或网络再试 |
| 邀请链接只是一串码 | 回生成结果页点“复制邀请链接”；应以 `https://` 开头。若结果页已丢失，请管理员重新生成 |
| 注册提示没有邀请码 | 通过完整邀请链接打开，确认 URL 保留了 `?invite=…` 部分 |
| 邀请无效或已过期 | 检查是否已使用或被撤销；让管理员生成新邀请 |
| 模型测试失败 | 核对服务商、接口基础地址、模型名和 Key 是否对应；查看服务商余额、额度和网络状态 |
| 测试成功仍提示没配置 | 测试后还需要点击“保存模型配置” |
| 生成计划却没有 QQ 提醒 | 是否采纳生效；绑定是否验证；机器人是否在线；是否已经到提醒时间；是否免打扰、暂停或到达上限 |
| QQ 聊天没有回复 | 确认好友私聊和已验证绑定；检查个人模型配置、机器人及后台状态；过一会重发一句短文字 |
| 机器人说连不上模型 | 回模型配置测试连接；不必因此解绑 QQ |
| 回复数字却提示找不到任务 | 裸数字依赖近期单项提醒；核对当天任务序号后用“完成 2”等明确指令 |
| AI 说了调整建议，但网页没变 | 目前自然语言聊天不直接修改计划，需要在网页更新情况、重新生成并采纳 |
| 用了新网址后要重新登录 | 不同域名不会共享浏览器登录状态，用原账号登录即可，不用重新注册 |

## 13. 一天的推荐用法

**开始一天时：**检查今天的固定安排和目标，生成计划，阅读并采纳。

**收到提醒时：**先做一个容易开始的小动作。完成后反馈；没做完也可以如实记录一半或跳过。

**临时有变化时：**把变化补充到“我的情况”，重新规划并确认。也可以先在 QQ 与 AI 讨论怎么调整更合适。

**结束一天时：**核对未反馈任务，回顾安排是否过满，更新明天需要考虑的情况。开始新的一天后，再检查是否需要生成并采纳当天计划。

## 14. 管理员运行提示

当前手机访问依赖这台电脑提供服务，并不是已经部署在全天运行的云服务器上。

| 组件 | 停止后的影响 |
| --- | --- |
| 网站服务 | 手机或电脑无法正常使用网页 |
| 数据库 | 登录、计划、绑定及其他业务无法正常读写 |
| QQ 后台任务服务 | 提醒派发、好友申请处理和 QQ 入站处理受影响 |
| NapCat／机器人登录 | QQ 收发中断，需要恢复登录或连接 |
| cpolar 隧道 | 手机公网入口不可用，本机入口可能仍能使用 |

当前没有设置整套服务开机自启。电脑关机、重启或休眠后，要检查这些组件是否恢复。免费隧道地址变化时，需要同步更新登录域名和邀请分享域名；只把新链接发给用户，而不更新网站配置，可能造成登录失败。

需要长期固定网址、电脑关闭后仍可使用时，应另行部署常驻服务器，并配置固定域名、备份和运维。这部分不属于当前已完成的本机临时访问能力。
