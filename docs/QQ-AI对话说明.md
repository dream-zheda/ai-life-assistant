# QQ AI 对话（2026-11-05）

完成网页 QQ 绑定、配置可用模型并保持机器人在线后，直接私聊发送自然语言即可聊天。无需额外启动聊天开关。

## 已实现

- 复用每个用户在网页保存的模型地址、模型名和加密 API Key，支持现有 OpenAI 兼容协议（如 DeepSeek）。
- 回答参考本人个人情况、本人当地日期、当天已生效计划和最近 12 条历史消息。成功对话保存在现有 Conversation / Message 表。
- 固定进度指令优先处理，其确认文字也回发 QQ；其余文字进入 AI 对话。
- 缺配置、认证失败、网络失败、空回复均有明确提示。单条输入最多 1000 字符，输出最多 500 tokens，模型请求超时 25 秒。
- 签名、好友私聊、机器人身份、已验证绑定及用户状态校验沿用现有机制；重复事件不重复调用模型。

## 使用边界

- 自由聊天提供建议，不直接改计划；实际计划变更仍在网页确认。已有「完成 2」等指令可记录进度。
- 当前为单 worker 实现。短期对话计数限流不等于跨进程严格限流。
- OneBot 明确返回可重试失败时最多额外重试两次。未知发送结果不自动重发，避免重复消息。尚无持久化对话发送队列；进程退出或接口一直失败时，用户需重发问题。
- OneBot accepted 只代表接口接受，不能证明 QQ 客户端收到。QQ 桥接离线时聊天和 QQ 提醒均不可用。
- 对话和必要个人上下文会发给用户选择的模型服务商。当前不支持图片、语音和群聊。

## 验证

全仓类型检查通过；165 个单元测试通过；隔离 PostgreSQL 的 132 个原集成测试通过。新增的完整聊天回归测试及同文件其余 14 项通过，验证网页加密凭据可由 worker 解密、模型请求、QQ 回复、事件去重、历史顺序、用户隔离与网络故障提示。

测试使用模拟模型与发送器，没有向真实 QQ 联系人发送测试消息，也没有用这些结果代替实际收信验收。
